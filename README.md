# 🏥 Medicare Plus — Healthcare Website

A modern, responsive healthcare website designed to present medical services, healthcare professionals, and convenient appointment enquiry options.

## 🌐 Live Demo

[Visit Medicare Plus](https://arppra2007-lgtm.github.io/medicare-plus/)

## ✨ Features

- 🏥 Modern healthcare website design
- 📱 Responsive layout
- 🩺 Medical services showcase
- 👨‍⚕️ Doctor profiles section
- 📅 Appointment enquiry form (demo)
- ⭐ Patient testimonials showcase (fictional demo content)
- 📍 Contact information section
- 🎨 Clean and professional UI
- ⚡ Interactive website elements

## 🛠️ Technologies Used

| Technology | Purpose |
|---|---|
| HTML5 | Website structure |
| CSS3 | Styling and responsive design |
| JavaScript | Interactive functionality |
| GitHub Pages | Website hosting |

```bash

```

2. Open the project folder.
3. Open `index.html` in your browser.

## 🎯 Project Purpose

Medicare Plus is a portfolio project created to demonstrate frontend web development skills, responsive design, and modern healthcare website presentation.

**Note:** This is a portfolio demonstration. Doctor profiles, testimonials, contact details, and appointment form content are fictional examples. The form does not book real appointments.
